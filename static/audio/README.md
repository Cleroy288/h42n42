# Audio Assets Directory

Place your custom sound files in this directory:
- `music.mp3` / `music.ogg`: Background game soundtrack (loops automatically)
- `contaminate.mp3`: Sound played when a creet is contaminated
- `heal.mp3`: Sound played when a sick creet is cured at the hospital
- `death.mp3`: Sound played when a berserk or mean creet dies
- `gameover.mp3`: Sound played when the game ends
- `spawn.mp3`: Sound played when a new creet is born

Note: If any of these files are missing, the game runs smoothly with graceful fallback.
